## Per-case detail

### W1 — SSRF — agent URL-fetch tool reaches cloud metadata
- **Maps to:** API7:2023 SSRF / A10:2021 · CWE-918
- **Request:** `POST /tools/fetch  url=http://169.254.169.254/latest/meta-data/iam/security-credentials/`
- **Vulnerable app:** [200] iam-role: acme-app; secret: AKIAIOSFODNN7EXAMPLE  _( SSRF: fetched internal metadata endpoint )_
- **Hardened retest:** [403] egress blocked: host not on allowlist  _( SSRF fix: egress allowlist + internal-range denylist )_
- **Mitigation:** Egress allowlist + block internal/link-local ranges; never fetch attacker-supplied hosts by raw IP.

### W2 — IDOR / BOLA — read another user's conversation
- **Maps to:** API1:2023 BOLA / A01:2021 · CWE-639
- **Request:** `GET /conversations/conv-1002   (as user-alice; conv owned by user-bob)`
- **Vulnerable app:** [200] bob: my card ending 4242 was double charged  _( IDOR: returned another user's transcript )_
- **Hardened retest:** [403] forbidden: not your conversation  _( IDOR fix: ownership check on the object )_
- **Mitigation:** Enforce object-level ownership on every access; authorize the subject against the object, not just the route.

### W3 — Broken authentication — admin config with no valid token
- **Maps to:** API2:2023 Broken Auth / A07:2021 · CWE-306
- **Request:** `GET /admin/config   (Authorization: empty)`
- **Vulnerable app:** [200] {'db_dsn': 'postgres://acme:not-real@db.internal/acme', 'aws_key': 'AKIAIOSFODNN7EXAMPLE'}  _( broken auth: secrets served without a valid token )_
- **Hardened retest:** [401] unauthorized  _( auth fix: constant-time token check, deny by default )_
- **Mitigation:** Deny by default; constant-time token comparison; no unauthenticated path to secrets.

### W4 — Reflected XSS — search echoes active content unescaped
- **Maps to:** A03:2021 Injection (XSS) · CWE-79
- **Request:** `GET /search?q=<script>alert(document.cookie)</script>`
- **Vulnerable app:** [200] <p>No results for: <script>alert(document.cookie)</script></p>  _( reflected XSS: active content echoed unescaped )_
- **Hardened retest:** [200] <p>No results for: &lt;script&gt;alert(document.cookie)&lt;/script&gt;</p>  _( XSS fix: HTML-escape reflected input )_
- **Mitigation:** Context-aware output encoding (HTML-escape reflected input); CSP as defense-in-depth.

### W5 — SQL injection — tautology dumps all users' history
- **Maps to:** A03:2021 Injection (SQLi) / API8:2023 · CWE-89
- **Request:** `GET /history?term=' OR '1'='1   (as user-alice)`
- **Vulnerable app:** [200] [{'id': 1, 'user': 'user-alice', 'q': 'refund policy?'}, {'id': 2, 'user': 'user-bob', 'q': 'billing address change'}, {'id': 3, 'user': 'user-admin', 'q': 'rot  _( SQLi: tautology bypassed the user filter, dumped all rows )_
- **Hardened retest:** [200] []  _( SQLi fix: parameterized query + user scoping )_
- **Mitigation:** Parameterized queries / prepared statements; keep the user-scope filter server-side.
